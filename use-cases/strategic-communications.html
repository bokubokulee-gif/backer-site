Inspect the assumptions

Interpretation priors for task support / role threat / human review are operators 0.30 / 0.55 / 0.15; team leads 0.55 / 0.20 / 0.25; system owners 0.20 / 0.10 / 0.70. Message weights are efficiency 1.45 / 1.15 / 0.55; accountability 1.30 / 0.55 / 1.10; joint pilot 1.20 / 0.40 / 1.45. Multiply prior by message weight and normalize. Conditional pilot-choice probabilities are 62%, 12% and 44%. These assumed weights illustrate Bayesian updating; they are not a semantic assessment of the wording.
