RESEARCH PREVIEW 02 / STUDY DESIGN

From a market to the wider attention field.

The first preview asks how modeled traders respond. This second study asks where a topic travels across the web—and which attention persists. Its target environment is 5,000 generative agents, grounded in permitted aggregate traces and an opt-in audience panel.

Today this page animates anonymous markers over authored examples. It does not run 5,000 language-model agents, collect live platform data, or establish predictive accuracy.

See the evidence required to advance →
01 / CALIBRATE THE TOPIC
Separate recurring topics from bursts. Cluster permitted posts and links, remove duplicates and likely automated traffic, then normalize prevalence and velocity within each platform, language, and a declared rolling window. Report missing coverage; never add raw views across platforms.
02 / BUILD THE ENVIRONMENT
Use MiroFish / OASIS-style graph-to-environment design: modeled audience strata, bounded feeds, ranking, memory, exposure, and timestamped action logs. Agent Reach informs collection routes; it does not supply a representative human sample.
03 / OBSERVE ATTENTION
Public post and link activity are proxies. Test notice, dwell, revisit, and costly action separately using consented diaries, browser-data donations, creator analytics, saved-link histories, and small panel tasks. Do not infer belief from a repost or join identities across platforms.
04 / FREEZE, THEN RESOLVE
Before each 24h, 72h, or 7d window, freeze inputs and forecasts. Score topic-platform share and cohort return against future observations and simple persistence, trend, and network baselines. Keep consented randomized tests separate from scenario comparisons.
